Sans publicité

Les jeux et leurs images sont hébergés dans ce dépôt. Aucun script publicitaire n’est chargé. Les favoris et sauvegardes restent dans le navigateur. Adaptations des sources · Provenance des fichiers.

GitHub Pages et Internet Archive assurent l’hébergement et peuvent traiter des données techniques : politique GitHub · conditions Internet Archive.

À propos des versions officielles

L’ancienne adaptation étudiante Subway Runner a été retirée. Les versions officielles de Subway Surfers, Hill Climb Racing, Drive Mad, Slope IO, Stickman Climb et Moto X3M ne sont pas incluses : aucune version permettant leur republication autonome sans publicité n’a été obtenue pour ce projet.

Projet indépendant de Poki, Nintendo, RobTop, SYBO, Fingersoft, Fancade et MadPuffers. L’accès sur une tablette gérée dépend de la configuration de l’établissement.
