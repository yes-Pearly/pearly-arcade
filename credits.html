Sources & licences

Pearly Arcade héberge des jeux open source existants. Le code des jeux n’a pas été réécrit. Ce projet est indépendant de Poki, Google et des auteurs crédités.

2048

Créé par Gabriele Cirulli. Code original · Licence MIT · Également présent sur Poki.

Le moteur est conservé. La mention affirmant que la copie est le site officiel a été remplacée par une attribution explicite.

Dino / T-Rex Runner

Jeu de Chromium, extrait pour le Web par wayou. Code source du port · Licence BSD à trois clauses · Également présent sur Poki.

Le moteur et les graphismes sont conservés. Seuls le titre, le texte d’aide et la dépendance à une police Google distante ont été ajustés.

Publicité et données

Aucune publicité, aucun traceur et aucune ressource distante ne sont chargés par le portail ou les deux jeux. Les scores et les parties de 2048 sont enregistrés localement dans le navigateur. GitHub Pages assure l’hébergement et peut enregistrer des données techniques : politique de confidentialité GitHub.

Disponibilité

Moto X3M, Basketball Stars et les autres jeux propriétaires de Poki ne sont pas inclus. Leur republication nécessite des fichiers et des droits adaptés. L’accès depuis un appareil géré dépend de la configuration de l’établissement.
